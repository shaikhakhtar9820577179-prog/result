# XI Science Result Register 2025–26

A static, offline results viewer built from the college's Tabulation Register (360 students, divisions A, C, D).

## Features
- Search by name, roll no, student ID or GR no
- Filter by division, gender, result and class; sortable columns
- Per-student subject-wise marks
- Summary stats, division comparison, subject averages, top 5
- CSV export, light/dark theme

## Run locally
Open `index.html` in a browser. No build step or server needed.

## Host on GitHub Pages
Repository **Settings → Pages → Deploy from a branch → `main` / root**.

## Files
- `index.html` – page structure
- `style.css` – styling
- `script.js` – app logic plus the embedded student data

> Note: this repo contains students' personal data (names, dates of birth, marks). Keep the repository **private**, or do not publish it on a public GitHub Pages site.
